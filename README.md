# LIGHT CAVALRY

Платформа для анализа текста с поиском в Telegram.

## Быстрый старт

### 1. Установить Rust
```bash
curl --proto '=https' --tlsv1.2 -sSf https://sh.rustup.rs | sh
source ~/.cargo/env
```

### 2. Настроить .env
Открой файл `.env` и заполни:
```env
APP_LOGIN=ebar          # твой логин
APP_PASSWORD=543        # твой пароль
DATABASE_URL=sqlite:data.db
TG_API_ID=12345678      # с my.telegram.org
TG_API_HASH=abcdef...   # с my.telegram.org
HOST=127.0.0.1
PORT=3000
```

### 3. Запустить
```bash
cargo run --release
```

Открой браузер: **http://127.0.0.1:3000**

---

## Функции

| Вкладка | Что делает |
|---------|-----------|
| **Повторы** | Находит повторяющиеся фразы (2–10 слов), подсвечивает в тексте |
| **Сравнение** | Сравнивает два текста по биграммам, показывает % схожести |
| **Символы** | Ищет английские буквы в русском тексте и спецсимволы |
| **Поиск** | Ищет фрагменты текста (по 6 слов) в твоих Telegram чатах |
| **Счётчик** | Слова, предложения, символы, время чтения, сложность |
| **Настройки** | Тема интерфейса, смена логина/пароля |

---

## Telegram подключение

1. Зайди на **my.telegram.org** → создай приложение → скопируй `api_id` и `api_hash`
2. Вставь их в `.env` (или введи прямо в интерфейсе при подключении)
3. В разделе **Поиск** нажми "Подключить"
4. Введи номер телефона → получи код в Telegram → введи код
5. Сессия сохранится в базе — повторный вход не нужен

> Сессия хранится в `data.db` только на твоём компьютере. Доступ снаружи невозможен.

---

## Смена пароля

В разделе **Настройки** → введи текущий пароль + новые данные.  
После сохранения **перезапусти сервер** (`Ctrl+C` → `cargo run --release`).

---

## Сессии по IP

Авторизация запоминается на 30 дней по IP-адресу.  
При следующем входе с того же IP пароль не спрашивается.
